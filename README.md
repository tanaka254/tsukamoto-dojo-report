# 塚本道場 月次レポート

各道場主が月次の会員数・チラシ配布を登録し、理事会向けに集計するウェブアプリです。
データはすべて Google スプレッドシート「塚本道場 理事会ダッシュボード」に保存されます（Apps Script 経由）。

- 公開ページ: https://tanaka254.github.io/tsukamoto-dojo-report/
- 数え方: 道場生数は **実働会員 = 在籍 − 休会**（2026年9月 キックオフミーティング決定）

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（GitHub Pages で配信）。先頭の `API_URL` に Apps Script のURLを設定 |
| `apps-script/Code.gs` | スプレッドシート側のバックエンド（ウェブアプリ）＋ チラシ配布報告フォーム |

## セットアップ（初回のみ）

1. スプレッドシートの「拡張機能 → Apps Script」を開き、既存のコードを `apps-script/Code.gs` の内容で置き換えて保存
2. `APP_PASSCODE` を共通パスコードに変更
3. 「デプロイ → 新しいデプロイ → ウェブアプリ」（実行ユーザー: 自分／アクセス: 全員）→ 表示された `…/exec` のURLをコピー
4. `index.html` の `API_URL` にそのURLを設定して GitHub に反映（GitHub Pages が数分で更新）
5. 道場主に「公開ページのURL」と「パスコード」を共有

## データの置き場所（スプレッドシート内）

- 月次入力 … 『年間入力』シート（AA列: 更新日時, AB列: 入力者）
- 料金 … 『料金マスタ』シート
- 目標 … 『app_目標』シート（自動作成）
- チラシ報告 … 『チラシ配布報告』シート（I列: ID）。Googleフォームの回答もここに集約
